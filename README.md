> 你搬进这栋老楼的顶层 501。第一晚，楼上有东西在拖动家具。
> 可房东说过：这栋楼最高就是五楼，你楼上是天台，只放得下水箱。

## 故事

2019 年，王建国买下 501，报警说天花板夹层里有人。警察来了，什么都没找到，登记表上写着「第 4 次了」。后来他“搬走”了，东西都没拿。

多年后的今天，你搬了进来。楼上的声音，是他还在。

## 玩法

1. **开场**：先问你叫什么（不填也行），之后故事会用这个名字。
2. **四夜**：关灯，手掌贴天花板，在户型图上找震动最强的一点。左右声道会跟着位置走。
3. **手机**：业主群、房东、老陈、王建国的私聊；每条回复都会改变「他注意到你」的程度。
4. **监控**：回放到 03:12，红色人影出现——时间会**冻结**在那一刻，声音切断、屏幕闪红、心跳。
5. **纸**：维修单、快递单、论坛帖、日记、报警记录，读完会冒出「你」的反应。
6. **四个结局**：报警 / 抬头看 / 搬家 / 回到床上，每个都有「这个结局是什么意思？」。

## 界面

- 右下角 **存档**：4 个槽位，随时存、读、删
- 右下角 **设置**：音量滑杆（0 即静音）、文字恐怖谷（小 / 中 / 大）
- 自动存档仍在（`jiaceng.save.v3`），槽位另存（`jiaceng.slots.v1`）

## 文件

> 引擎与剧情已分离：改剧情只动 `content.js`，不要动 `wig-engine.js`。

| 文件 | 作用 |
|---|---|
| `index.html` / `wig.css` | 入口与样式 |
| `wig-engine.js` | 通用引擎（场景、音频合成、聊天、监控、存档），不含本作剧情 |
| `content.js` | 全部剧情、聊天、文档、结局 + 本作引擎配置 |
| `图标.ico` / `启动.bat` / `_制作/` | 快捷方式与生成源 |
